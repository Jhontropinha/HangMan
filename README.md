# 🐍 Jogo da Forca em Python

Um jogo da forca clássico desenvolvido em Python puro (linha de comando) para exercitar manipulação de arquivos, estruturas de dados (listas e conjuntos), tratamento de strings e laços de repetição.

## 🚀 Como executar
1. Certifique-se de ter o Python 3 instalado.
2. Abra o terminal no diretório do projeto.
3. Execute o script principal:
   ```bash
   python main.py
